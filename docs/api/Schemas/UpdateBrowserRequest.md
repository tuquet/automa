# UpdateBrowserRequest

Request payload for modifying an existing browser profile

**Type**: `object`

## Properties

| Name | Type | Description |
|---|---|---|
| `name` | string,null | New profile display name |
| `timezone` | string,null | New emulated timezone ID |
| `userAgent` | string,null | New custom User-Agent |
